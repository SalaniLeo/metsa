# Metsa
Weather (but not only) website for Ferrara, italy.

### Data sources:
  - Open Meteo
  - Sat24
  - NOAA
  - Blitzortung
  - Meteociel
  - 3BMeteo (Protezione Civile)
  - Eumetsat

### Features:
  - Nowcast:
      - All nowcast data provided by OM, customizable in settings
      - Radar
      - Cloud coverage
      - Aurora Borealis
      - Radar
      - Lightnings
  - Forecast:
      - Both daily and hourly values for every possible data provided by OM
      - Graph visualization for selected data, in daily or hourly views
      - Sky cloud coverage with sky transparency index for taking astrophotos
  - Near real-time data:
      - Maps:
          - Fog
          - IR 3.9
          - IR 10.8
          - WV 6.2
          - Visible spectrum
          - Radar (Map up to 1 hour before)
          - Satellite (Map up to 6 hours before)
